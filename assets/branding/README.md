# Generated MegaProxy artwork

[MegaProxyIdentity](https://github.com/andre487/MegaProxyIdentity) SVGs are the source of truth.
The retired raster masters are archived there under `Generative/AndroidMegaProxy`.

Run `bundle exec fastlane android update_graphics` to regenerate committed Android, store
and documentation artwork. `identity-lock.json` records the Identity revision, source/output
SHA-256 hashes and renderer version. `IDENTITY-LICENSE` applies to Identity-derived artwork.
Normal app builds use committed outputs and never download artwork.

The GitHub badge remains a local exception: `docs/assets/get-it-on-github.svg` and its
notices stay here; its PNG is generated by the same command. Screenshots are maintained separately.
