# MegaProxy branding assets

`megaproxy-launcher-master.png` is the current canonical raster artwork for the MegaProxy logo.
Use it as the visual source when regenerating derived application, store, or documentation assets.

Derived assets live with the component that consumes them:

- Android launcher resources: `app/src/main/res/mipmap-*`
- Store listing icon and graphics: `fastlane/metadata/android/*/images/`
- Repository and documentation graphics: `docs/assets/`

## GitHub download badge

`docs/assets/get-it-on-github.svg`, its PNG and notices are copied from AndroidMessage487.
The SVG contains outlined text; third-party attribution is in
[get-it-on-github-NOTICES.txt](../../docs/assets/get-it-on-github-NOTICES.txt).
README and installation guides use the PNG at a display height of 75 pixels.
