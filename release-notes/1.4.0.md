## English

- All proxy types now accept IPv6 proxy and jump-host addresses with or without brackets in profile settings and connection setup.
- Fixed JSON profile imports with IPv6 addresses and added correct IPv6 brackets to exported proxy links.
- Bootstrap DNS now queries AAAA records when no resolver supplies an A record and at least one returns a valid response without A records, allowing IPv6-only proxy and jump-host names while still requiring IPv4 access to the bootstrap DNS providers.
- Updated the launcher icons, adaptive icon layers and VPN notification icon.

## Русский

- Все типы прокси теперь принимают IPv6-адреса прокси и промежуточных узлов в скобках и без них в настройках профиля и при подключении.
- Исправлен импорт JSON-профилей с IPv6-адресами и добавлены корректные скобки для IPv6 в экспортируемых прокси-ссылках.
- Начальное разрешение DNS теперь запрашивает AAAA, если ни один резолвер не вернул A-запись и хотя бы один дал корректный ответ без A-записей, позволяя использовать имена прокси и промежуточных узлов только с IPv6, но по-прежнему требуя доступа по IPv4 к начальным DNS-провайдерам.
- Обновлены значки запуска приложения, слои адаптивного значка и значок VPN-уведомления.
