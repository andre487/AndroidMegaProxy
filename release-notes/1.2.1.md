## English

- Added device-wide VPN MTU settings with 1280, 1400 (default), 1500 and custom values from 1280 to 65535 bytes, applied to all profiles after reconnecting.
- MegaProxy is now selected for split tunneling by default and added once to existing lists on upgrade, while subsequent manual exclusion is preserved.
- The speed test now warns when MegaProxy is excluded from split tunneling and explains how to enable VPN-route measurements.
- Fixed DNS failures at the 64-flow limit by reclaiming completed idle UDP flows without discarding pending replies or TCP DNS streams.
- Imports and subscription updates now preserve local insecure-DNS and invalid-certificate approvals for an unchanged resolver and clear them when the resolver changes.
- DoH queries, proxy bootstrap DNS and speed-test connections now try alternatives 200 ms apart instead of waiting for slow attempts to time out, using the first successful result and cancelling the remaining attempts.
- Fixed delays to other HTTPS proxy connections when closing a redundant HTTP/2 session was slow.
- Subscription updates can now replace primary and backup HTTPS source URLs while retaining local authentication, update interval and pause state, with saved subscription credentials also sent to replacement URLs.
- Imports and subscription updates now reuse omitted passwords and SSH keys only when the protocol, server, port and account remain unchanged, with Jump credentials checked against their respective endpoints.
- Basic Auth usernames containing a colon are now rejected for HTTP proxies and HTTPS Jump authentication.

## Русский

- Добавлена общая для устройства настройка MTU VPN со значениями 1280, 1400 (по умолчанию), 1500 и произвольным значением от 1280 до 65535 байт, применяемая ко всем профилям после переподключения.
- MegaProxy теперь выбран для раздельного туннелирования по умолчанию и однократно добавляется в существующие списки при обновлении, а последующее ручное исключение сохраняется.
- Тест скорости теперь предупреждает, если MegaProxy исключён из раздельного туннелирования, и объясняет, как включить измерения через VPN.
- Исправлены сбои DNS при достижении лимита в 64 потока за счёт освобождения завершённых неактивных UDP-потоков без потери ожидающих ответов и потоков TCP DNS.
- Импорт и обновления подписки теперь сохраняют локальные разрешения небезопасного DNS и недействительных сертификатов для прежнего резолвера и сбрасывают их при его смене.
- Запросы DoH, начальное разрешение адреса прокси и соединения теста скорости теперь пробуют альтернативы с интервалом 200 мс вместо ожидания тайм-аута медленной попытки, используя первый успешный результат и отменяя остальные попытки.
- Исправлены задержки других соединений через HTTPS-прокси при медленном закрытии лишней сессии HTTP/2.
- Обновления подписки теперь могут заменять основной и резервные HTTPS URL источников, сохраняя локальную авторизацию, интервал обновления и состояние паузы, причём сохранённые учётные данные подписки отправляются и на новые URL.
- Импорт и обновления подписки теперь сохраняют пропущенные пароли и ключи SSH только при неизменных протоколе, сервере, порте и пользователе, а учётные данные Jump проверяются по соответствующим узлам.
- Имена пользователей Basic Auth с двоеточием теперь отклоняются для HTTP-прокси и авторизации HTTPS Jump.
