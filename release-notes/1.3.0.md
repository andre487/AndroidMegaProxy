## English

- Added opt-in app ownership checks on Android 10+ that apply after reconnection, check new TCP connections, block unknown owners and VPN ping, and either cache UDP permission for up to one second per flow in Standard mode or check every outgoing datagram in Advanced mode.
- Visibility now shows the running source-validation level and whether saved changes require reconnection.
- Combined connection and speed tests in Diagnostics, which starts a connection test on opening, unlocks speed checks after success, and provides a shared log that can be copied or exported.
- Speed tests now default to HTTP/2 with HTTP/1.1 fallback, while HTTP/3 remains selectable.
- Added an optional operator-provided authentication check host for regular HTTPS-over-TCP diagnostics, where an explicit 407 confirms rejection while timeouts and unexpected statuses remain inconclusive.
- Authentication check hosts now transfer through JSON as proxy.knockHost with legacy browser.knockHost import support, and changing only this host does not require VPN reconnection.
- Fixed cancellation of destination SSH handshakes through Jump when the jump server stops responding, so stopping or cancelling the connection no longer waits on the stalled handshake.

## Русский

- Добавлена включаемая по желанию проверка приложения-источника на Android 10+, которая применяется после переподключения, проверяет новые TCP-соединения, блокирует неизвестных владельцев и ping внутри VPN, а для UDP кеширует разрешение до секунды на поток на стандартном уровне или проверяет каждую исходящую датаграмму на расширенном.
- «Видимость VPN» теперь показывает действующий уровень проверки источника и необходимость переподключения для применения сохранённых изменений.
- Тесты соединения и скорости объединены в «Диагностике», которая запускает тест соединения при открытии, открывает проверку скорости после успеха и предоставляет общий журнал для копирования и экспорта.
- Проверка скорости теперь по умолчанию использует HTTP/2 с переходом на HTTP/1.1, а HTTP/3 остаётся доступен для выбора.
- Добавлен необязательный хост проверки авторизации от оператора для диагностики обычного HTTPS по TCP, где явный ответ 407 подтверждает отказ, а таймауты и неожиданные статусы остаются неопределёнными результатами.
- Хост проверки авторизации теперь переносится через JSON как proxy.knockHost с поддержкой импорта старого browser.knockHost, а изменение только этого хоста не требует переподключения VPN.
- Исправлена отмена SSH-рукопожатия с конечным сервером через Jump при зависании промежуточного сервера, поэтому остановка или отмена подключения больше не ждёт зависшего рукопожатия.
