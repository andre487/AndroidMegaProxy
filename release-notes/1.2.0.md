## English

- Added Cloudflare speed tests for underlying and VPN connections, with 10/25/50 MB transfers, HTTP/3, HTTP/2 or HTTP/1.1 preference, and exit IP, country, latency, download and upload results.
- Moved VPN visibility to the main menu and added ProxyCheck reputation checks for each connection’s public IP, caching successful verdicts locally for 24 hours.
- Added explicitly approved TCP/UDP DNS with numeric resolver addresses, with UDP DNS using a direct connection outside the VPN for HTTPS/TCP and SSH transports.
- Custom DoH now accepts root URLs and uppercase HTTPS schemes, rejects mismatched or malformed DNS responses, and offers a separately confirmed certificate-verification exception that does not change proxy certificate checks.
- Fixed stale Start, Stop and reconnect commands overriding newer actions, including delayed SSH host-key approval resuming a connection after Stop.
- Applying reviewed imports now preserves newer changes to unselected profile options and leaves global settings untouched unless their import was selected.
- Added total configuration storage limits that reject oversized imports, edits and subscription refreshes without replacing the saved configuration, while keeping oversized legacy stores readable for recovery.
- Added a “Route MegaProxy through VPN” switch in selected-app routing mode that stays synchronized with the app-list selection.
- Update results and download or install actions now scroll into view after checking for updates or downloading an APK.
- Fixed concurrent SSH session rotation attempts potentially closing a replacement session while preserving active channels.

## Русский

- Добавлены тесты скорости Cloudflare для обычного подключения и VPN с передачей 10/25/50 МБ, выбором предпочтительного HTTP/3, HTTP/2 или HTTP/1.1 и результатами IP-адреса выхода, страны, задержки, скорости загрузки и отправки.
- Проверка видимости VPN перенесена в главное меню и дополнена проверкой репутации публичного IP каждого подключения через ProxyCheck с локальным кешированием успешных результатов на 24 часа.
- Добавлен DNS по TCP/UDP с явным подтверждением и числовым адресом сервера, причём UDP DNS для транспортов HTTPS/TCP и SSH отправляется напрямую вне VPN.
- Пользовательский DoH теперь принимает URL без пути и схему HTTPS в верхнем регистре, отклоняет несоответствующие или некорректные DNS-ответы и предлагает отдельно подтверждаемое отключение проверки сертификатов без изменения проверки сертификатов прокси.
- Исправлено выполнение устаревших команд запуска, остановки и переподключения поверх новых действий, включая возобновление подключения после остановки при отложенном подтверждении ключа SSH.
- Применение импорта после проверки теперь сохраняет более свежие изменения невыбранных параметров профиля и не затрагивает глобальные настройки, если их импорт не выбран.
- Добавлены общие ограничения объёма конфигурации, отклоняющие слишком большие импорты, изменения и обновления подписок без замены сохранённых данных, при этом старые хранилища сверх лимита остаются доступными для восстановления.
- В режиме маршрутизации выбранных приложений добавлен переключатель «Направлять MegaProxy через VPN», синхронизированный с выбором в списке приложений.
- После проверки обновлений или скачивания APK результаты и действия скачивания или установки теперь прокручиваются в видимую область.
- Исправлено возможное закрытие новой SSH-сессии при одновременных попытках ротации с сохранением активных каналов.
