# MASQUE α (HTTP/3)

MASQUE — экспериментальная поддержка, обозначенная **α** в интерфейсе. Используйте текущий
релиз; APK из PR предназначены для тестирования. См. [установку](installation.md).

## Настройка подключения

Выберите **MASQUE α (HTTP/3)** в профиле и введите имя сервера, UDP-порт (по умолчанию 443),
логин и пароль. Оставьте проверку сертификата включённой. Откройте **Диагностику** и проверьте
выходной IP и страну. При таймауте уточните у оператора, доступен ли UDP-порт из вашей сети.
Если вы сами обслуживаете прокси, см. [настройку GOST (на английском)](../en/masque.md#configure-gost).

## Отпечатки и ограничения

- Если сайты с HTTP/3 не открываются через GOST 3.3.0 с отпечатком Firefox, попробуйте Chrome.
  Крупные UDP-пакеты могут отбрасываться. GOST 3.3.0 также не поддерживает передачу UDP
  к буквальному IPv6-адресу через MASQUE.
- Для ручного отпечатка MASQUE укажите QUIC JA3 в профиле. Для переноса этой настройки используйте
  экспорт JSON. Выбранный отпечаток относится к соединению с прокси.
- Если при завершении TCP-соединения через GOST 3.3.0 теряется конец ответа, сообщите об этом
  оператору сервера. [Подробности совместимости (на английском)](../en/masque.md#fingerprints-and-limits).

## Необязательный HTTP/3 в HTTPS

В HTTPS-профиле можно включить **«Предпочитать HTTP/3 α»**, сохранив тип
HTTPS. Приложение пробует MASQUE на том же хосте и номере UDP-порта в течение
трёх секунд. Для отката сервер должен также предоставлять HTTPS по TCP. Если
QUIC недоступен, отпечаток или настройки сервера не поддерживаются, выбирается
существующий HTTPS-транспорт (HTTP/2 или HTTP/1.1). Главный экран и кнопка «Тест»
показывают предупреждение: при откате обычный UDP блокируется, а перехваченный
DNS использует выбранный [режим](dns.md).

Ошибки сертификата, авторизации, защиты сокета и неизвестные ошибки не приводят
к откату. После выбора HTTP/3 ошибки остаются на этом транспорте; активные
соединения не переносятся. Выбор повторяется при новой VPN-сессии или тесте.
Настройка выключена по умолчанию и игнорируется для типов без HTTPS.
Отдельный MASQUE-профиль по-прежнему требует HTTP/3 без отката. Глобальный
отпечаток браузера используется в пределах поддержки QUIC; неподдерживаемые
Edge/custom JA3 используют HTTPS. JSON сохраняет
`profiles[].proxy.preferHttp3`; обычные ссылки на прокси эту настройку не содержат.

Для HTTPS с Jump поддержка MASQUE нужна на обоих узлах. Имя конечного прокси
разрешается удалённо через CONNECT-UDP. При недоступности любого узла вся
цепочка использует HTTPS/TCP через Jump. Учётные данные и проверка сертификата
сохраняются для каждого узла. При недостаточном размере пакета с отпечатком Firefox цепочка переходит на HTTPS/TCP.
