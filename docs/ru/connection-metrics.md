# Метрики качества соединения

[English](../en/connection-metrics.md) · [Все руководства](index.md)

На главном экране показаны объём и скорость переданных данных. RTT — задержка от телефона
до первого прокси и обратно. Она не включает время ответа сайта. Для TCP показаны повторные
отправки, для HTTP/3 — число исходящих QUIC-пакетов, объявленных потерянными за последние
пять минут. Ни один из этих счётчиков не показывает процент потерь при скачивании.

Измерения используют обычный трафик. Если данных для оценки нет, значение отсутствует.
При новом подключении статистика сеанса сбрасывается. Высокая задержка сама по себе не
вызывает переключение на резервный профиль. Предупреждение после повторных сбоев может
означать как блокировку, так и недоступность прокси.

## MTU VPN-интерфейса

Настройки → MTU: 1280, 1400 (рекомендуется, по умолчанию), 1500 или своё целое
значение от 1280 до 65535 байт. 1280 — [минимальный MTU канала для IPv6](https://www.rfc-editor.org/rfc/rfc8200#section-5),
а не универсальный стандарт для VPN. 1400 оставляет запас для накладных расходов туннеля;
большее значение не обязательно повышает скорость. Настройка общая для всех профилей устройства
и применяется после переподключения.
Настройка локальная и не входит в переносимый формат конфигурации/подписки.
Это ограничение внутреннего IP-пакета, а не согласованного размера QUIC datagram или MTU пути.


## Тест, Скорость и Видимость VPN

В главном меню доступны «Диагностика» и «Видимость VPN». При открытии «Диагностики» запускается тест соединения; после его успеха становится доступна проверка скорости, запускаемая вручную. Обе операции пишут в общий ограниченный журнал внизу экрана: его можно копировать и экспортировать в текстовый файл. Повторный тест очищает журнал и блокирует проверку скорости до успеха. Во время замера скорости повторный тест недоступен.

Проверки измеряют разные вещи:

| Экран | Значение |
| --- | --- |
| Диагностика: тест соединения | Подключение прокси, HTTPS и выходной IP/страна; независимые UDP/HTTP3 проверки поддерживаемых режимов. Выходной IP можно скопировать. Если VPN отключён, может использоваться временный тестовый VPN. |
| Диагностика: скорость | Активная передача Cloudflare отдельно через основную сеть и VPN; постепенная таблица IP, флаг/код, HTTP и TLS на отдельных строках, задержка, скачивание и отправка. |
| Видимость VPN | Системные признаки VPN на устройстве и репутация публичного IP по ProxyCheck для каждого доступного маршрута. Эвристики и репутация не доказывают обнаружение VPN всеми приложениями. |

При раздельном туннелировании для замера VPN-маршрута выберите MegaProxy. По умолчанию
он выбран; при обновлении он однократно добавляется в существующие списки приложений.
Последующее явное исключение сохраняется.

В узких окнах «Скорость» показывает результаты основной сети и VPN отдельными блоками; в широких — сравнительной таблицей. Предпочитаемая версия HTTP допускает переход на младшие версии; правила описаны ниже.

Скорость использует 10/25/50 десятичных MB в каждом направлении каждого маршрута
(10 000 000/25 000 000/50 000 000 байт). Два маршрута и оба направления могут расходовать
до четырёх выбранных объёмов плюс служебный трафик. По умолчанию выбран h2 с переходом на h1.
При выборе h3 разрешён переход на h2, затем h1; h1 остаётся h1. Переход возможен только на этапе выбора протокола. Ошибка сертификата или передачи данных завершает тест.
Задержка — медиана **времени до первого байта** трёх пустых скачиваний с накладными расходами
запроса; это не время SSL handshake, ICMP ping или пассивный RTT главного экрана.
Для измерений с выбором протокола используется `h3.speed.cloudflare.com`.
Лог содержит DNS/TCP/TLS/QUIC, протокол/fallback, HTTP status, повторное соединение, байты
и время передачи, без ответа сервиса и выходного IP.
Уход из «Диагностики» или пересоздание её интерфейса отменяет замер скорости и удаляет его результаты. Общий журнал в памяти сохраняется до следующего теста соединения или перезапуска процесса. Home/сворачивание само по себе не отменяет запросы. События также пишутся в постоянный журнал с ротацией;
очистить или экспортировать его можно отдельно в **Настройки → Диагностический журнал**.

Успех ProxyCheck кешируется на 24 часа для каждого публичного IP. Дневной лимит, ошибка сети
и неизвестный формат — разные состояния; недоступные маршруты показываются отдельно.
Список сервисов диагностики приведён в [README](../../README.md#privacy-and-security).
