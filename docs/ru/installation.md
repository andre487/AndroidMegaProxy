# Установка MegaProxy из APK

[English installation instructions](../en/installation.md)

MegaProxy поддерживает Android 8.0 (API 26) и новее. Официальные APK публикуются в разделе
[GitHub Releases](https://github.com/andre487/AndroidMegaProxy/releases/latest).

**[Скачать рекомендуемый universal APK](https://github.com/andre487/AndroidMegaProxy/releases/latest/download/mega-proxy-universal.apk)**

## Выбор APK

Откройте последний релиз, разверните список **Assets** и скачайте файл с окончанием
`universal.apk`. Это основной рекомендуемый вариант: он поддерживает все перечисленные ниже
архитектуры. Приложение пока не добавлено в F-Droid. Для скачивания релизных APK аккаунт GitHub
не нужен. При обновлении по возможности сохраняйте выбранный вариант APK.

| APK | Для каких устройств |
| --- | --- |
| [`mega-proxy-universal.apk`](https://github.com/andre487/AndroidMegaProxy/releases/latest/download/mega-proxy-universal.apk) | Рекомендуется для телефонов, планшетов и эмуляторов; включает все поддерживаемые архитектуры |
| [`mega-proxy-arm64-v8a.apk`](https://github.com/andre487/AndroidMegaProxy/releases/latest/download/mega-proxy-arm64-v8a.apk) | Уменьшенный APK почти для всех современных телефонов и планшетов Android |
| [`mega-proxy-armeabi-v7a.apk`](https://github.com/andre487/AndroidMegaProxy/releases/latest/download/mega-proxy-armeabi-v7a.apk) | Старые 32-битные устройства ARM |
| [`mega-proxy-x86_64.apk`](https://github.com/andre487/AndroidMegaProxy/releases/latest/download/mega-proxy-x86_64.apk) | 64-битные устройства Android на x86 |
| [`mega-proxy-x86.apk`](https://github.com/andre487/AndroidMegaProxy/releases/latest/download/mega-proxy-x86.apk) | Старые 32-битные устройства Android на x86 |

APK для конкретной архитектуры меньше по размеру, но его стоит выбирать только когда архитектура
устройства точно известна. Нужен только один APK: это самостоятельные установщики.
Архивы **Source code**, а также `.aab` и ZIP с отладочными символами в старых релизах
не подходят для установки приложения на телефон.

## Установка на телефон

1. Откройте на телефоне страницу
   [последнего релиза MegaProxy](https://github.com/andre487/AndroidMegaProxy/releases/latest).
2. Разверните раздел **Assets** и нажмите на файл с окончанием `universal.apk`.
3. Если браузер предупреждает, что APK-файл может быть опасен, убедитесь, что адрес начинается с
   `https://github.com/andre487/AndroidMegaProxy/`, и подтвердите скачивание.
4. После завершения скачивания откройте файл из уведомления браузера или системного приложения
   **Загрузки**.
5. Если Android заблокировал установку, нажмите **Настройки** в показанном предупреждении и
   разрешите пункт **Установка неизвестных приложений** или **Разрешить из этого источника** для
   браузера либо файлового менеджера, из которого был открыт APK.
6. Вернитесь к системному установщику и нажмите **Установить**. После установки вы можете снова
   отключить разрешение установки из этого источника.
7. Откройте MegaProxy и создайте или импортируйте профиль своего SSH- или HTTPS CONNECT-сервера.
   Приложение не предоставляет серверы и реквизиты доступа. Инструкция по настройке сервера:
   [MegaProxyServer](https://github.com/andre487/MegaProxyServer).
8. Выберите **Проверить** в меню главного экрана, затем нажмите **Подключить**. При первом подключении
   подтвердите системный запрос Android на VPN: это позволяет направлять трафик через ваш прокси.

Названия системных пунктов могут немного отличаться в зависимости от версии Android и
производителя телефона. Не скачивайте APK MegaProxy со сторонних сайтов и зеркал.

## Проверка скачанного файла

Скачайте `SHA256SUMS` из **того же релиза**, что и APK. В терминале в папке загрузок
выполните команду для своей системы:

```shell
# macOS
shasum -a 256 mega-proxy-universal.apk
# Linux
sha256sum mega-proxy-universal.apk
```

```powershell
# Windows PowerShell
Get-FileHash .\mega-proxy-universal.apk -Algorithm SHA256
```

Подставьте имя своего APK. Сравните все 64 шестнадцатеричных символа с записью для этого файла
в `SHA256SUMS`; регистр букв не важен. При несовпадении не устанавливайте файл: скачайте APK
и контрольные суммы заново из одного релиза. Проверка выявляет повреждение или изменение файла,
но сама по себе не подтверждает подлинность источника.

## Установка через ADB

В качестве альтернативы APK можно скачать на компьютер и установить через [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools).
Включите на телефоне отладку по USB, подключите его к компьютеру и подтвердите системный запрос на
разрешение отладки. Убедитесь, что устройство отображается командой:

```shell
adb devices
```

Затем установите или обновите приложение:

```shell
adb install -r mega-proxy-universal.apk
```

Укажите фактическое имя скачанного APK. Параметр `-r` устанавливает новую версию поверх текущей и
сохраняет данные совместимой установленной версии. В `adb devices` должен быть статус `device`,
а не `unauthorized` или `offline`. Если устройств несколько, используйте
`adb -s SERIAL install -r mega-proxy-universal.apk`, подставив серийный номер из списка.
В Windows запускайте `adb.exe` из Platform Tools или добавьте эту папку в `PATH`.
После использования можно отключить отладку по USB.
См. [руководство ADB](https://developer.android.com/tools/adb#move).

## Обновление

Чтобы обновить MegaProxy:

1. Проверьте GitHub Releases и скачайте APK новой версии, желательно того же варианта.
2. Откройте его на телефоне и подтвердите обновление существующего приложения.
3. Не удаляйте MegaProxy перед обновлением: удаление приложения стирает профили, известные ключи
   SSH и остальные локальные настройки.

Android установит обновление поверх текущей версии только при совпадении идентификатора приложения
(`net.megaproxy487`), совместимой подписи и не меньшем коде версии. Официальные релизные APK
подписываются ключом проекта. У debug-сборки или сборки другого распространителя подпись может
отличаться, поэтому обновление поверх неё может быть невозможно.

У APK для отдельных архитектур код версии немного выше, чем у universal из того же релиза.
Переход на universal в рамках одной версии может быть отклонён как понижение версии.
Выбирайте более новый релиз; не обходите проверку понижения и не удаляйте приложение ради этого.
Перед миграцией экспортируйте нужные конфигурации; храните экспорт как конфиденциальные данные.

После установки или обновления рекомендуется открыть приложение, проверить выбранный профиль и
в меню главного экрана выбрать **Проверить** перед первым подключением.

## Тестовые артефакты из pull request

Если нужно проверить изменение, откройте комментарий со ссылками на APK в pull request либо
успешную Android-проверку. Ссылки находятся в отчёте job и разделе **Artifacts** запуска workflow.
Для скачивания нужен вход в GitHub и доступ к репозиторию:
[инструкция GitHub](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts).

Скачайте `megaproxy-pr-<номер>-debug-apk`, распакуйте ZIP и установите `app-debug.apk` по инструкции
выше. Срок хранения — 14 дней; если Android-проверки пропущены, нового APK нет.
Используйте эмулятор или запасное устройство: debug APK имеет тот же идентификатор приложения,
но другой ключ подписи и не обновит официальный релиз. Между запусками CI debug-подпись тоже
может различаться. Не удаляйте рабочую установку ради проверки PR.

`megaproxy-pr-<номер>-unsigned-release-apk` содержит неподписанный `app-release-unsigned.apk`
для проверки сборки. Это не готовый установочный релиз. Для повседневного использования
скачивайте подписанные APK из GitHub Releases.

## Если установка не удалась

| Симптом | Что проверить |
| --- | --- |
| Приложение не установлено / конфликт пакетов | Подпись и версию уже установленной сборки; см. раздел обновления. Не удаляйте приложение без экспорта нужных данных. |
| Несовместимое устройство / `INSTALL_FAILED_NO_MATCHING_ABIS` | Выберите universal или подходящую архитектуру; нужен Android 8.0 или новее. |
| Ошибка разбора / повреждённый пакет | Убедитесь, что скачан APK, а не ZIP/AAB; сравните контрольную сумму. |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | Выберите более новый релиз вместо APK с меньшим кодом той же версии. |
| Недостаточно места | Освободите память устройства и повторите установку. |
| ADB показывает `unauthorized` | Разблокируйте телефон и подтвердите разрешение отладки с компьютера. |
| Приложение установилось, но не подключается | Проверьте сервер, реквизиты профиля, доступ к сети и разрешение VPN. Установка APK не настраивает сервер. |

Если установку запрещает администратор рабочего устройства, обратитесь к нему.
[Справка Android по установке приложений](https://support.google.com/android/answer/9457058).
