# MASQUE review — 2026-10-10

Dated snapshot of the fixes and tests added to PR #70 after rebasing on `main`.

## Fixed defects

- A live QUIC connection that received GOAWAY remained the current session forever.
  New CONNECTs now use a new session; existing streams drain on the old connection.
  Retry is limited to opening a stream before any CONNECT request is sent.
- One oversized UDP packet terminated the tun2socks association. Unsupported packets
  are dropped whole, logged once per flow and excluded from forwarded traffic totals.
  The client also respects its advertised receive limit: a Firefox-sized echo otherwise
  causes GOST to close the association. Small subsequent packets use the same flow.
- A write blocked behind the uQUIC DATAGRAM queue ignored new deadlines and stream
  closure. Cancellable queue admission now unblocks without leaving a deferred send
  or closing unrelated streams on the shared QUIC connection.
- A shared custom JA3 could not serve both TCP TLS and QUIC, which requires extension
  57. MASQUE uses its existing per-profile JA3 field; HTTPS uses the global TLS JA3.
  Persistence, editing, schema-valid exports and imports cover both independently.
- A TCP custom JA3 with legacy version 771 and supported_versions accidentally capped
  negotiation at TLS 1.2. The supported_versions maximum now permits TLS 1.3; a real
  TLS-1.3-only local handshake and real GOST custom HTTPS/jump cases cover this.
- API 26 exposed retry delays rounded up by the ten-second service monitor. A retry
  now wakes at its actual deadline after startup cleanup; switching profiles also
  wakes recovery, without charging the old profile's failure to the replacement.
  The existing 90-second real MASQUE-blackhole → custom HTTPS scenario is retained.

## Logging review

- Disabled tun2socks' direct logger, which printed private endpoints outside the
  persistent sanitizer. Production logs use structured diagnostic events.
- MASQUE logs record stages, status 407, TLS/cipher/ALPN, QUIC version/capabilities,
  elapsed times, local numeric session/flow identifiers and numeric QUIC error codes.
  They omit wire connection IDs, target identities, peer-controlled error strings,
  authentication headers and packet contents. Local Close does not create false DPI
  alarms. Unexpected remote closure remains diagnosable.
- Strengthened persistent redaction for URI schemes, quoted credentials, PEM keys,
  scoped/mapped IPv6 and host-key pins. Crash logs retain exception classes, stack
  frames and classified reasons, without exception messages or arbitrary thread names.
  SSH host-key decisions still reach the UI; their pins are removed before persistence.
- Repeated connection/DoH/SSH/UDP events are limited to 20 per category per 10 seconds
  with bounded state and a suppression count on the next window. Recovery callbacks
  precede this limiter; lifecycle, crashes and user-action events remain available.

## Validation scope

Fastlane native/race tests, Android JVM/lint/debug/unsigned-release checks, Python
checks and instrumentation builds are required. The expanded disposable API 26 and
API 35 suite exercises real TUN/JNI and GOST: Chrome, Firefox, Randomized and custom
TCP/UDP; stop/restart; bad authentication and recovery; self-signed certificate refusal
and explicit exception; oversized UDP recovery on the same socket; per-app routing;
and timeout-driven custom MASQUE → HTTPS failover. Existing Keystore, system consent,
notification and document-provider scenarios run alongside these transport cases.

This suite is not proof of every manual H01–H11 case. A trusted matching certificate,
external DNS-leak capture, actual browser HTTP/3 to an origin, physical Wi-Fi/cellular
handover and a usable external IPv6 uplink remain separate release gates in the
[release procedure](../en/release-testing.md). GOST's IPv6 literal CONNECT-UDP and
Firefox's inner 1200-byte QUIC Initial limits remain documented alpha limitations.
